# 🏟️ CubeSports

**CubeSports** is a modern football web application built with Next.js, providing live scores, fixtures, league standings, team statistics, and match highlights.

🟢 **Status:** Active Development

🌐 **[Visit CubeSports](https://thecub4.vercel.app/Cubesports)**

![CubeSports Preview](https://github.com/user-attachments/assets/f86df4eb-3f2a-4314-b14a-2b882a268b1c)

## ⚡ Features

- ⚽ Live football scores and updates
- 🗓️ Fixtures and match results
- 🏆 League standings
- 📊 Team and match statistics
- 🎬 Football highlights
- 📱 Mobile and desktop support

## 🛠️ Built With

- Next.js
- JavaScript
- React
- CSS
- Vercel

## 📡 Disclaimer

**CubeSports does not host, stream, or rebroadcast live football matches.**

Football information and available highlights are sourced from third-party services.

For live match broadcasts, please use officially licensed broadcasters in your region.

CubeSports is an independent project and is not affiliated with any football league, club, or broadcaster.
